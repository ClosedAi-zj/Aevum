# 验收仪器（acceptance/）的 Python 依赖。

# 为什么这个文件在 acceptance/ 而不是仓库根：产品是纯 Rust，`cargo build` 与打出来的

#     python -m venv .venv
#     .venv/Scripts/python.exe -m pip install -r acceptance/requirements.txt

# 下面是本机实际跑通冻结与比对的确切版本，改版本前先确认金标仍逐字节可复现：
#     python acceptance/oracle/freeze_golden.py ...   # 连跑两遍，输出必须逐字节相同
