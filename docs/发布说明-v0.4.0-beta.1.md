# 光时 · Lumen Studio v0.4.0-beta.1 — 发布说明

**中文** · [English](发布说明-v0.4.0-beta.1.en.md)

新仓库首个 beta 版本。相对此前的 v0.3.0，本版包含三个里程碑的累积推进：

## 1. Lightroom 对齐 · UI 接入轮

- 新增 7 个影调滑杆，全部中文标签、口径对齐 Lightroom：
  「高光过渡」（曝光高光肩部 rolloff）、「线性对比」（线性光域混合对比度）、
  「黑场软化」/「白场软化」（抛物线软拐点）、「HDR 尾部」（曲线 x>1 延伸）、
  「锐化保护」（噪声自适应边缘保护）、「颗粒亮度」（双向亮度调制）
- 新参数默认 0 = 旧渲染路径逐位一致；旧工程 JSON 缺字段自动兜底
- RAW 导入默认值新增「锐化保护 20」（仅首次导入生效，不覆盖已打开工程）
- 去马赛克算法可切换（单元平均 / 方向自适应）：信息页 → 引擎分组，切换后全链重解，不落盘
- RAW 解码降级信息从 stderr 挪进界面（信息页「RAW 降级」行）

## 2. 算法里程碑轮

- **降噪升级**：多尺度（粗层引导滤波自动降采样）+ σ 噪声模型
  （自动 MAD 估计 + 手动覆盖）；默认关闭 = 旧单尺度逐位一致
- **去雾**：完整暗通道先验（大气光估计 → 透射率引导滤波精修 → 大气散射复原），
  线性域全程；新增「暗通道去雾」「去雾对比」两滑杆，旧去雾占位保留
- **输出锐化**：导出专用 USM（软阈值 + 增量限幅 + 尺寸感知增益），
  屏幕 / 哑光纸 / 光面纸三档预设；Off 档行为不变
- Python oracle 逐式同步，金标扩至 47 case（新增 4 case，Rust/Python 最大差 1e-5）

## 3. 性能与重构轮（行为保持）

- 蒙版几何 / 曲线 LUT / 直方图 / 去闪曲线四层缓存：蒙版悬停场景帧耗约 −8%，
  曲线 PCHIP 查表路径约 3000×；零行为变化
- `shell.rs`（约 12000 行）拆分为 14 个子模块，机械搬运经逐字审计（202/202 项一致）
- 会话复位逻辑收编为单一函数，消除五处重复复位块

## 质量数字

- 全仓 668 测试 / 0 失败；clippy 门禁通过（唯一已知白名单项：layout.rs 测试代码 1 条）
- 金标 47 case 全过；重冻结两遍逐字节一致
- selftest 各模块布局形状计数与重构前逐位一致

## 已知限制

- beta 期不保证工程文件 / 预设跨版本兼容
- 部分算法常数为经验值（TODO(fit)），如去雾透射下限、降噪 σ 参考值、锐化三档阈值
- 「手动噪声 σ」滑杆低段（约 ≤28）暂不生效（自动 σ 兜底门控），待拟合后放开
- lumen-mcp 工具未接入本轮 4 个新参数（下轮补）
