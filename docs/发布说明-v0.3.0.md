# 光时 · Lumen Studio v0.3.0 — 使用版说明

**中文** · [English](发布说明-v0.3.0.en.md)

首个对外可用版本。从相机序列照片做到成片：对齐 → 合成 → 裁剪（含运镜）→ 调色 → 配乐 → 变速与运动模糊，一个窗口完成。

## 运行要求

- Windows 10/11 x64。
- 无需安装：解压即用。`tools\ffmpeg.exe` 供导出成片与音频探测使用，删掉它界面照常跑，只是导不出视频。

## 快速上手

1. 双击 `lumen.exe`，把一个**帧文件夹**（或照片文件夹）拖进窗口；
2. 顶部工作区下拉在六个模块间切换：**序列 / 去闪 / 显影 / 构图 / 成片 / 声音**，上一步的产物自动流进下一步；
3. **显影**：右侧面板调光（基本/色彩/效果/细节/颗粒/镜头校正/色彩分级…），分组标题右侧蓝点 = 该组有改动，点组头可折叠，「复位」一键回默认；
4. **成片**：选规格导出视频（HEVC/H264），导出进度在状态栏；
5. 顶部「视图」菜单：标尺、网格、前后对比、左侧预设栏/右侧面板显隐；「外观与布局」（Ctrl+,）：明暗主题、皮肤、主色、圆角、**密度（紧凑/标准/宽松）**、字号、布局四轴。

## 偏好与数据

- 偏好落盘 `%APPDATA%\lumen\settings.json`（明暗/主色/圆角/密度/字号/布局）；删掉即回默认。
- 序列的护带目录是 `<序列>/.lumen/`，缓存与工程数据都在里面，删除只影响缓存重建。
- 全部处理在本机完成，无联网行为。

## 插件（实验性）

滤镜插件是独立子进程（协议：一行 JSON + 裸 tile，512 分块），界面崩溃不了画布：

- 插件放 `%APPDATA%\lumen\plugins\<id>\plugin.toml`，或设 `LUMEN_PLUGINS` 指向插件目录；
- 「插件」菜单里直接运行；运行中状态栏显示进度，可随时「✕ 取消」；
- 同一插件连续崩溃 3 次会提示停用（取消不计入）。

## 本版主要变更（相对 0.2.2）

- 界面整体对齐设计稿：单行推子、渐变山形直方图、左预设栏、画布顶文档页签、胶片条蓝框选中、状态栏重排；标题栏只留品牌图标；
- **控件规格表**：40+ 个调色参数一处登记，推子/分组圆点/复位三处同源，读数带单位（px 等）；
- **行高密度档**：紧凑/标准/宽松，随偏好落盘；
- **插件后台任务**：进度上报 + 取消 + 崩溃计数，Nik 类秒级插件不再卡界面；
- 全量测试 600+ 项通过；无显示器自检（--selftest）通过。

## 已知限制

- Camera Raw/XMP 互通与内置解码器在后续版本（路线图见仓库看板）；
- 插件市场 v1 只做免费 + 厂商外链（未定案）；
- 浅色主题在实拍素材上的对比度建议实际过一遍。

## 命令行

```
lumen.exe                 # 正常启动
lumen.exe --demo          # 内置演示序列
lumen.exe --selftest      # 无显示器自检
lumen.exe --mcp           # Agent 控制面（stdio JSON-RPC）
```
