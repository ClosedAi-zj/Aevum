# 去闪预对齐（圣杯）

**中文** · [English](去闪预对齐.en.md)

日转夜延时里，相机一直在追光：拉长快门、开大光圈、抬 ISO。去闪器看到的亮度是
「场景光 × 相机补偿」，它分不清哪部分是真实的光线变化、哪部分只是相机在动——于是
要么把参数台阶当闪烁压掉（吃掉日落），要么把真实变暗当闪烁压掉（吃掉日夜过渡）。

**预对齐**用 EXIF 的曝光三要素把相机补偿剥掉，在「场景域」跑去闪，再把增益并回校正。
效果是：台阶没了，日落还在。

## 1. 什么时候该开

- 日转夜 / 夜转日（俗称「圣杯」延时），光比跨度几档到十几档；
- 拍摄时你手动拧参数追光，或用了自动曝光让画面别过曝/欠曝；
- 画面看着「亮度一路上没怎么变」，但你知道天确实黑了——这正是过渡被测光吃掉的样子。

恒光场景（室内定格、阴天匀速）开着也不会坏，只是没有收益：EV 台阶本来就不存在。

## 2. 原理：一条公式

```
corr = offset + (EV − EV_ref)
```

- `offset`：场景域去闪给出的逐帧校正，压的是**测光误差**（±0.1 档量级）；
- `EV − EV_ref`：这次拍摄里**真实发生的重曝光**，`EV_ref` 取全部有效 EV 的中位数；
- 两者之和可以远超单帧 ±3 档的限幅。限幅管的是「别把闪烁压过头」，管不着
  「本来就计划好的重曝光」——圣杯序列上超过 3 档是预期，不是坏帧。

锚点为什么取中位数而不是第一帧：坏帧、缺帧都不会挪锚；更实际的理由是并回之后
**总校正的中位数为 0**，整条片子不会被预对齐顺手整体提亮或压暗——对齐只重分配每帧
曝光，不改总曝光。

## 3. 面板里怎么用

去闪面板勾「按 EXIF 预对齐（圣杯）」，下面会多一行覆盖情况：

- `128 / 160 帧有曝光三要素`——有 EV 的帧才对齐；
- `这批帧没有曝光三要素（ISO/快门/光圈），预对齐不会生效`——一个都没有时**不装作
  生效**，其余参数（窗口/强度/通道）照常起作用。

「分析结果」里那条亮度曲线是**并回后的总校正**，所以圣杯序列上它会呈现完整的日夜
落差，而不是被压平的锯齿。

工程文件会记住这个开关：重开工程时 `def_offsets` 与开关同一口径，不会出现「数字在、
解释没了」。

## 4. agent（MCP）里怎么用

```
aevum_deflicker_analyze { "align_exif": true }
```

回执里三项值得看：

- `align_exif`：这次到底按哪种口径算的；
- `ev_frames`：真正读到曝光三要素的帧数（0 就是空转）；
- `align_note`：空转时的说明，正常为 `null`。

`offsets.min/max/mean_abs` 是并回后的总校正，`series[].ev` 同理——圣杯序列上
`max - min` 会明显大于不开对齐时。`align_exif` 也会被记住，`aevum_save_project` 写进工程。

## 5. 边界与已知限制

- **缺三要素的帧不对齐也不猜**（截图、PNG、被修图软件洗过 EXIF 的 JPEG、某些手机
  HDR 合成产物）：按洞处理，交给去闪插值，那张帧自己的校正为 0。半个台阶进分析会
  变成假跳变，比如实。
- **一个 EV 都没有**：整体退回普通去闪，开关等于没开——但界面与回执都会说出来。
- **自动曝光序列**：EV 台阶里混着相机自己的测光决策与真实光线，对齐后得到的是
  「曝光固定时会看到的样子」，正是延时想要的；但如果你本来想保留自动曝光的呼吸感，
  别开这项。
- **与分通道（RGB）叠加**：三个通道乘同一个增益（相机补偿不挑颜色），色闪仍由分通道
  去闪处理。
- **`Stats` 口径分裂**：`jitter_before/after` 在场景域报告（对齐后显著变小＝收益所在）；
  `max_ev` / `mean_abs_ev` 是总校正（含计划内重曝光），所以圣杯上超过 `MAX_EV` 属正常。

## 6. 判据清单

| 判据 | 咬的是什么 |
|---|---|
| core `exif_alignment_drops_the_pre_deflicker_residual_...` | 台阶（1 档）必须降一个量级到 0.1 档的测光误差；用**最大相邻差**而不是 P95——台阶只占 5% 的帧，P95 恰好抓不到 |
| core `the_aligned_output_restores_the_day_night_transition_the_meter_ate` | 输出必须保留 > 6 档过渡（关着时 < 2 档）。把「并回 offsets」注释掉必红（只剩 0.99 档） |
| core `missing_evs_become_holes_and_no_evs_at_all_is_a_noop` | 洞帧校正为 0；无 EV 时与普通去闪逐位一致；锚点钉成 0 必红（整体挪 3 档） |
| ui `deflicker_align::the_exif_switch_hands_...` | 面板开关真的接进分析（不接线必红：只还原 0.97 档）；EV 表少一帧必红（校正表缩水） |
| mcp `deflicker_align::the_agent_switch_folds_...` | 真 JPEG + 真 APP1 的台阶进到逐帧 EV（忽略开关必红）；`ev_frames` / `align_note` 口径 |
| `project_roundtrip` | 开关活过工程文件；旧工程缺这一项读成 `false` |
