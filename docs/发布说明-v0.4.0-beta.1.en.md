# Lumen Studio v0.4.0-beta.1 — release notes

[中文](发布说明-v0.4.0-beta.1.md) · **English**

The first beta from the new repository. Relative to v0.3.0, it accumulates three milestones:

## 1. Lightroom alignment — UI wiring round

- Seven new tonal sliders, all with Chinese labels and behaviour matched to Lightroom:
  "highlight rolloff" (highlight shoulder on exposure), "linear contrast" (contrast blended in
  linear light), "black soften" / "white soften" (parabolic soft knees), "HDR tail" (curve
  extension for x > 1), "sharpening protection" (noise-adaptive edge protection), and "grain
  luminance" (two-sided luminance modulation).
- New parameters default to 0, which keeps the old rendering path bit-for-bit identical;
  project JSON that lacks the fields falls back automatically.
- RAW import defaults gain "sharpening protection 20" (first import only; never overrides an
  already-open project).
- The demosaic algorithm is now switchable (cell average / directional): Info tab → Engine group.
  Switching re-decodes the whole chain and persists nothing.
- RAW decode fallback messages moved from stderr into the UI (Info tab, "RAW fallback" row).

## 2. Algorithm milestone round

- **Denoise upgrade**: multi-scale (coarse layer drives the guided-filter downsample) plus a
  σ noise model (automatic MAD estimate with manual override); off by default, which keeps the
  old single-scale path bit-for-bit identical.
- **Dehaze**: full dark-channel prior (atmospheric light estimate → transmittance refined by a
  guided filter → atmospheric scattering inversion), all in linear light; two new sliders
  ("dark-channel dehaze", "dehaze contrast") while the old dehaze placeholder stays.
- **Output sharpening**: an export-only USM (soft threshold + increment clamp + size-aware gain)
  with screen / matte paper / glossy paper presets; the Off preset changes nothing.
- The Python oracle follows formula by formula; golden data grows to 47 cases (4 new, max
  Rust/Python difference 1e-5).

## 3. Performance and refactor round (behaviour-preserving)

- Four cache layers — mask geometry, curve LUT, histogram, deflicker curve: mask-hover frames
  cost about 8% less, the curve PCHIP lookup path is roughly 3000×; zero behaviour change.
- `shell.rs` (~12000 lines) split into 14 submodules, the move audited character by character
  (202/202 items identical).
- Session-reset logic collected into a single function, removing five duplicate reset blocks.

## Quality numbers

- 668 tests across the workspace / 0 failures; the clippy gate passes (one known allowlist entry:
  a single lint in `layout.rs` test code).
- All 47 golden cases pass; two consecutive re-freezes are byte-identical.
- Per-module layout shape counts from `--selftest` are bit-identical to pre-refactor.

## Known limitations

- During beta we do not promise cross-version compatibility for project files or presets.
- Some algorithm constants are empirical (`TODO(fit)`): the dehaze transmittance floor, the
  denoise σ reference, the three sharpening thresholds.
- The lower range of the "manual noise σ" slider (roughly ≤ 28) has no effect yet (the automatic
  σ gate takes over); it will open up once fitted.
- `lumen-mcp` does not expose this round's four new parameters yet (next round).
