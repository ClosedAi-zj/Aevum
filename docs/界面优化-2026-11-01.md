## 落地口径

### #4 主界面精简（已落地）

**做法**：把「哪些组首屏展开」从散落在代码里的隐式默认（`collapsed` 初始为空 =
全展开）改成一张显式登记表 `state::GROUP_SPECS`：

```rust
in_module("basic", Module::Develop, true),    // 每张照片必动 → 展开
in_module("curve", Module::Develop, false),   // 深加工，占半屏 → 折叠
in_tab("info", "info-meta", true),            // dock 页的分组另按页归堆
```

**判断口径**：每张照片、每次导出都会动的那几组展开；设一次就不再碰的（相机镜头
配置、水印、HDR/全景合并）折叠。参考 Lightroom——打开一张图只看见「基本」是展开的。

**效果（selftest 形状数，默认/全展开）**：显影 1144/2193，成片 653/675，
序列 555/577。显影首屏少画约一半，十八段长滚变六段。

**顺手补的两件事**：

1. **折叠态落盘**。`settings.json` 加 `collapsed: Option<Vec<String>>`——
   `None` = 没表过态（用默认），`Some(vec![])` = 用户全点开了（尊重他）。
   写盘走帧尾单一出口（`settings_dirty` → `tick` 里写一次），不逐处搓文件。
2. **右键分组头**：只看这一组 / 全部收起 / 全部展开（Lightroom 的 Solo Mode）。
   只在右键菜单里，不常驻按钮——一周用一次的动作不占像素。作用域按
   「模块 + dock 页」算，跨作用域不连坐。

**回归口径**：`--selftest` 每个模块现在画两遍（默认态 + 全展开态），
默认态保住首屏排版、全展开态保住展开后的布局覆盖；`tests/suite/i18n_coverage.rs`
同样两遍，否则折叠组里的文案会整段脱离翻译验收。

### #8 自动检查机制（已落地）

`crates/aevum-ui/tests/suite/ui_tokens.rs`，九条，分三类：

**钉「同一件事只有一个实现」**

| 测试 | 拦的是 |
| --- | --- |
| `no_floating_window_is_anchored` | `.anchor(…)` → 浮窗 immovable（UI-2 的病因） |
| `floating_windows_share_one_title_frame` | 新加的浮窗忘挂 `title_frame()`，退回默认方角 |
| `one_radius_for_the_whole_window` | `windows.rs` 出现第二处 `corner_radius`，或上两角不等、下两角不归零 |
| `floating_windows_use_soft_separators` | 窗内混回 `ui.separator()`（通栏实线读成「切开」） |
| `corner_radius_arguments_are_theme_tokens` | `corner_radius(3.0)` 这类字面量；只放行 `0`/`0.0`（显式直角） |

**钉「口径本身还站得住」**：`radius_scale_stays_ordered`（控件 < 容器 < 窗）、
`type_scale_stays_ordered`（小 < 标签 < 正文 < 标题）。

**钉「功能在且找得到」**：`appearance_entry_point_stays_in_the_top_bar`——齿轮
（外观/语言唯一可见入口）在，且点了真开窗。UI-7 的教训：功能不缺，缺的是入口。

**钉「一张表必须对得上调用点」**：`panel_groups_match_the_registry`——源码里每个
`group_header(…)` 的键都必须在 `GROUP_SPECS` 里登记，且表里没有没人用的孤儿键。
键名是字符串，打错一个字母不报错、只静默失效（默认折叠不生效、落盘读回被丢），
这条把它变成红灯。

验证方式：把四类缺陷（anchor / 去掉 title_frame / 上两角不等 / 混回 separator）
逐条故意写回源码，四条测试各自变红且报出行号与改法，再 `git checkout` 还原。
绿灯本身不算证据，红得准才算。

**为什么不管颜色**：`shell/` 下直写 `Color32` 有 60+ 处，多是画布叠加层（取景框
阴影、蒙版手柄、直方图渐变）与 macOS 交通灯固有色——那些本就是像素级常量，收进
token 只会把 `theme.rs` 变成垃圾场。颜色交给 `theme.rs` 的 WCAG AA 对比度测试与
`--selftest` 兜。

### 发版待办（别丢）

1. 七条都要写进 `CHANGELOG` 的下一版节。注意第 0 关（`acceptance/check_version.py`）
   要求 CHANGELOG 顶节的版号与 `Cargo.toml` 一致，所以**必须和版本号一起改**，

   组，其余组保持默认折叠 —— 文档截图会比以前「更干净」，但和旧图不一样。若某张
   图需要整屏展开，再给 `--shot` 加个「全展开」开关，别去改默认态。
