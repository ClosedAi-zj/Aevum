**English** · [中文](遗留台账.md)

> This table is the **only** backlog. Every `TODO(fit)` in code and every "pending" / "do not forget"
> in prose must have an entry here; and every entry must be closed with verifiable evidence (test
> name / commit / measured numbers).
>
> Rules:
> 1. **No unnumbered backlog.** A newly found issue gets a number the same day — it must not sit in
>    a code comment instead.
> 2. **Closing requires evidence.** "Done" is not evidence: it needs a test name, a side-by-side
>    measurement, or a release record.
> 3. **Deciding not to do it also closes it** — but the reason must be written down, and the `TODO`
>    marker removed from the code. Leaving the marker means "I know this is wrong and I am ignoring
>    it", and the next reader has to work it out all over again.
>
> Status: `open` / `in progress` / `closed` / `wontfix (with reason)`
>

## A. Parameter fitting debt

One method throughout: `TODO(fit)` means "this number has no basis". There are exactly two ways out —

- **Literature value**: the original paper or spec states this number; cite the source and change the
  marker to `(literature value)`;
- **Self-proving measurement**: build a scene whose correct answer is known, measure the mapping from
  parameter to observable quantity, and turn a guess into a measured choice. The criterion must be
  **independent of the reference implementation** — the golden file only proves Rust == Python, and a
  guessed value written into both sides is green forever.
