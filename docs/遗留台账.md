## A. 参数拟合债

清账方式统一：`TODO(fit)` 的意思是「这个数字没有依据」。消掉它只有两条路——

- **文献值**：原论文 / 规范里就写着这个数，标注出处，标记改成 `（文献值）`；
- **自证式测量**：构造一个已知正确答案的场景，测出「参数 → 可观测物理量」的映射，
  把「猜」变成「测过的选择」。判据必须是**不依赖参考实现**的（金标只证明 Rust ==
  Python，猜值写进两端就永远绿）。
