## 1. 调研结论

### 1.1 Camera Raw（15–17）的编辑面板组织（官方文档核实）

- **分区固定次序**：基本 → 曲线 → 细节 → 颜色混合器（HSL/颜色/黑白三模式）→
  颜色分级 → 光学 → 几何 → 效果 → 校准。每区一个可折叠的组头。
- **面板模式三档**（右键组头设置）：单开（点开一组收起其他，默认）/ 响应（按屏高
  自动开合）/ 多开。快捷键 Ctrl+1..9 直跳对应分区。
- **滑块交互**：标签在左、数值在右且可点击输入；双向滑块（曝光/色温）以中点为原点；
  双击滑块柄复位该条；Alt+点组头 Reset 复位整组；组头右侧小圆点=该组有改动。
- **每组有「眼睛」开关**：按住可临时隐藏该组调整，看前后对比。
- **预设与快照不占编辑面板**：它们是左侧工具条上与「编辑/裁剪/修复」并列的独立
  面板工具；「上一步」（历史）同样在工具条上。
- **直方图常驻面板顶部**，色温/色调等区域可在直方图上直接拖。

### 1.2 Lightroom Classic 的功能分域

调色全部在「修改照片」模块右侧一列；合并类工具（HDR/全景）是「照片」菜单下的
动作而非面板；快照/预设/副本/历史集中在左侧面板底部——**核心洞察：Adobe 把
「调一张照片的参数」和「用多张照片生成一张图」分成两个世界**。

### 1.3 本仓现状与差距

| 面 | 现状 | 与 ACR 的差距 |
| --- | --- | --- |
| 显影分区 | 基本/色彩/效果/细节/蒙版（展开）+ 外观/色阶/参数/曲线/HSL/黑白/分级/颗粒/配置/镜头（折叠），**尾部混着 调色副本/HDR/全景/星空堆栈/时间合成/焦点合成 六组** | 分区次序与 ACR 不同；HSL/黑白/色阶/曲线各自成组而不是一个混合器；合成类工具混进调色面板 |
| 组头 | 已有折叠 chevron / 悬停高亮 / 改动点 / 复位 / 右键「只看这组/全收起/全展开」/ 折叠态落盘 | 缺 ACR 的粗体标题+双线样式、单开模式开关、眼睛旁路 |
| 滑块 | 已有 标签76px+轨道+DragValue(52px)+行内复位，对齐旧设计稿 | 缺双向滑块中点刻度、双击复位 |
| 左栏 | 工具轨(52px) + 预设栏(LEFT_W：内置预设/快照/历史三节) | 「历史」与 dock「历史」页**完全重复**；预设栏占掉一整栏画布宽度 |
| 设计稿 | `mockups/lumen-studio-platform.html` 已不在仓库与磁盘（全历史检索过），视觉事实源=theme token + 代码注释 CSS 口径 + `docs/界面优化-2026-11-01.md` | 本次重构以本文件为新布局规格，实施后 UI token 判据（`ui_tokens.rs`）同步扩条目 |

## 2. 左栏收纳：预设/快照/历史/副本出侧栏

**目标**：左栏只剩 52px 工具轨，画布一次拿回一整栏宽度；次要功能不占显眼位置。

1. **删除左栏「历史」节**——dock「历史」页已有完整撤销/重做+步骤列表（`tabs.rs::history_tab`），
   左栏那份是重复视图。这不是搬家，是删冗余。
2. **预设 + 快照 + 调色副本 → 浮窗「预设与快照」**：
   - 复用 `title_frame()` 浮窗规范（`ui_tokens.rs` 八条守门照常管住）；
   - 内容三节：内置预设 / 快照 / 调色副本（copies 本质是「存一套参数+关键帧」，
     与快照同类，ACR 也把副本类归到快照域）；
   - 入口三处：工具轨顶部一枚 `Glyph::Sliders` 常驻图标（悬停「预设与快照 (Ctrl+K)」）、
     「显影」菜单项、快捷键 Ctrl+K；
   - 快照的「+」存档动作跟到浮窗栏头，语义不变。
3. **`state.show_left` 语义改为「预设与快照浮窗开关」**，settings.json 里的旧键
   读回时映射过去（老用户不会丢已存的快照——数据在 state，只动入口）。
4. 菜单里「左侧预设栏」的显隐开关文案同步改为「预设与快照」。

## 3. 右侧显影面板 ACR 化

**分区重排**（新旧对照，参数与 MCP/工程格式零改动，只动 UI 组织）：

| ACR 次序 | 新分组（本仓实现） | 由哪些旧组并成 |
| --- | --- | --- |
| 基本 | **基本**：白平衡（色温/色调）→ 色调（曝光/对比/高光/阴影/白/黑）→ 偏好（纹理/清晰度/去朦胧/鲜艳度/饱和度），区内三个次级小标题 | basic + color |
| 曲线 | **曲线**：区头下三枚模式片（参数 / 点 / 色阶），ACR 的 Curve 同构 | curve + parametric + levels |
| 颜色混合器 | **颜色混合器**：区头两枚模式片（HSL / 黑白），HSL 内色相/饱和度/明度 | hsl + mono |
| 颜色分级 | **颜色分级**（原 grade 不动） | grade |
| 细节 | **细节**：锐化 → 降噪 | detail（已含） |
| 光学 | **光学**：镜头校正 → 配置文件 | lens + profiles |
| 效果 | **效果**：颗粒 → 暗角 | effects + grain |
| 外观 | **外观（.cube）**（本仓特色，收尾） | look |
| — | **蒙版**（ACR 里 Masking 是工具轨入口，本仓保持组形态但移到分区末尾、紧贴画布工具） | masks |

**交互升级**（全部走 ACR 口径）：

1. **单开模式**：右键组头菜单补第四项「面板模式：单开 / 多开」，落盘 settings.json。
   单开=点开一组自动收其他组（ACR 默认），多开=现状。原「只看这一组」保留。
2. **双向滑块中点刻度**：signed 滑块轨道中点画 1px 竖向 notch（ACR 的原点记号），
   主题 token 画，不引裸色。
3. **双击轨道复位**：ACR「双击滑块柄复位」——双击轨道任意处回到 default（与行内
   复位点同走一条改值路径，历史记账不重复）。
4. **组头样式**：标题改小号粗体 + 组头下沿双线（粗线 1px + 下方 2px 处细线 0.5px，
   ACR 分区头的视觉签名）；改动点/复位/帮助的位置不动。
5. **眼睛旁路**（P1，若实现代价可控）：组头加 `Glyph::Eye`，按住临时旁路该组参数
   （渲染层按组旁路开关，放开即回）。若渲染链改动超出一轮范围，本条降级到
   「按住 Ctrl 点组头名 = 预览旁路」并在台账记录取舍。
6. 首屏展开策略维持 `GROUP_SPECS`（基本/细节/蒙版展开，其余折叠——ACR 默认也是
   只有基本展开）。

**成片/序列/去闪/构图/声音五个模块不动**——本次只动显影（调色）与左栏。

## 4. 调色与其他摄影功能分离

**新建模块 `Module::Merge`（中文「合成」/英文 MERGE）**，顶栏模块行第七项。

**次序更正（实现时定）**：`Module::ALL` 里追加在**末尾**（index 6），不是插在
「显影」之后。原因是 `Module::ALL` 的序号是外部契约——`Ctrl+Alt+数字` 快捷键与
`ui.module` 命令都按 0–5 认模块，中途插入会把「3 = 构图」的既有含义整体挪位，
用户的肌肉记忆与脚本一起失效。菜单上的视觉次序（合成排在显影右侧）与
`ALL` 的下标次序是两件事，前者由菜单行显式排列控制。

**Order correction (as implemented)**: appended to the end of `Module::ALL`
(index 6) rather than inserted after Develop. The index is an external contract --
`Ctrl+Alt+<digit>` and the `ui.module` command both address modules 0-5, and inserting
in the middle would shift "3 = Frame" for every user's muscle memory and every script.
The visual order in the menu row (Merge sits right of Develop) and the index order in
`ALL` are two different things; the former is explicit in the menu row.


- 迁入五组：HDR 合并 / 全景合并 / 星空堆栈 / 时间合成 / 焦点合成
  （`shell/adjust/merge.rs` 的 `hdr_group/pano_group/stack_group/timeblend_group/focus_group`
  整函数搬移，逻辑零改动）；
- 显影面板删除这五组的组头登记（`GROUP_SPECS` 对应行改 `Module::Merge`）；
- 「调色副本」组从显影移除 → 并进浮窗「预设与快照」第三节（§2.2）；
- 合成模块首屏展开 HDR 合并 + 时间合成（最常用两个），其余折叠；
- MCP 工具（`hdr_merge` 等）/ 工程格式 / 快捷键不动：模块只是 UI 组织维度。

**理由**：这五组全是「一组帧进来、一张图出去」的文件级工具，调色面板打开时
99% 的时间用不到它们；混排既拉长显影滚动（现 21 组），又让「改颜色」这个核心
动作在视觉上不占主导。

## 5. 字符重叠修复（低级错误零容忍）

已定位两处，均由代码审查找到（截图核实）：

1. **胶片条缩略图**：星级画在 `bottom-14..-7`、序号基线 `bottom-1`（MICRO 字高
   ~10px，顶到 `bottom-11`）——两者在 `bottom-11..-7` 纵向叠压，**每格都有**。
   修复：序号保持左下；星级改为**右对齐**（`cell.right()-3-5×8` 起），同一基线带
   水平分离（92px 格宽：序号 ~26px + 星级 40px，余量充足）；旗标仍在左上。
2. **状态栏挤压**：状态栏是单行多段（告警/进度/文件名/分辨率/帧/星级/状态/边车），
   窄窗口下 egui 不裁剪只挤压。修复：段间统一 8px+分隔点；「状态」段改
   `min_width` 自适应并 ellipsis；给 `status_bar` 补一条 `ui_tokens`/自检判据
   （窄宽 320px 渲染一遍，断言无负间距段）。
3. **全界面自检**：`--selftest` 已有形状计数，本次给胶片条/状态栏补「文本矩形
   相交断言」（画出的每对文本 galley 矩形不相交），同类低级错误进判据，不再靠人眼。

### 7.2 交互升级：实际落地四项 + 一项降级

1. **单开模式**（ACR 默认）：`state.panel_solo`（落 `settings.json`，`Option<bool>`，
   缺省 = 单开）；点开一组即收起同模块其余组（复用 `solo_group` 的作用域逻辑）；
   右键组头菜单第四项是勾选框，明确它是**设置**而非一次性动作。
2. **双向滑块中点刻度**：核对后确认**本仓早已实现**（`common.rs` 里 `min < 0 < max`
   时画 1px 竖标），本轮未改，只把它写进判据的覆盖范围。
3. **双击轨道复位**：同上，早已实现（`t.double_clicked()` 回 default，与行内复位点
   同一条改值路径、同一条历史记账）。
4. **组头样式**：标题字号 +0.5 → +1.0；分隔线从「顶部单线」改为「下沿双线」
   （实线 1px + 其上 3px 一道 55% 透明细线）——ACR 的分区头签名，也把「分区开始」
   与表格横线区分开。
5. **眼睛旁路**：**降级，本轮不做**。`aevum-core` 的调色链没有任何按组旁路机制，
   要做就得改渲染入口签名（`GradeParams` 之外多带一份临时旁路集）、预览与导出两路
   各接一次、再加「按住才生效」的事件态。这是独立一轮的工作量，按 §3.5 的降级条款
   处理，进 `遗留台账.md`。当前「单开模式 + 组头复位点 + 双击复位」已覆盖
   「快速对比某组效果」的主要路径。

### 7.3 两条新判据（都做过变异验证）

| 判据 | 抓什么 | 变异验证 |
| --- | --- | --- |
| `ui_tokens::text_never_overlaps_in_any_module` | 七个模块 × 中英两种语言各画一帧，同行文本矩形不许相交 | 把交付路径的 `truncate()` 退回字符数截断 → 红（`Render y=374 「预设表…」×路径 重叠 50.2px`）；把画布右边界夹取去掉 → 红（`Merge y=94 「Adjust」×「Undo Ctrl+Z」 32.9px`） |
| `ui_tokens::explicit_develop_field_lists_cover_the_spec_table` | 显式清单摆的五个分区，规格表里每条都必须出现 | 从基本区清单删掉 `Field::Saturation` → 红并直指 `basic / Field::Saturation` |

判据的三条口径都是被误报逼出来的，写在测试文档注释里：同串文字平移 ≤1.5px 是投影
（胶片条序号的黑影 + 白字）；只算 clip 内的可见部分；同行判定容差 3px、重叠容差 1px。
另外每个模块先跑 3 帧热身——egui 的 Panel 宽度按内容收敛，切模块后头几帧的画布边界
还在动，那是用户看不见的 16ms 过渡。

### 7.4 顺带修掉的一个真实缺陷

判据第一版就抓到：**切换模块后画布会压到 dock 页签上**。原因不在我们的代码——
`egui::Panel` 用「记忆宽度」缩剩余区，而面板自身 rect 已经吃 `exact_size`，切模块
换了 dock 内容后两者连续几十帧对不上（实测每帧 +1.6px，约 0.6 秒才归位）。修法：
`canvas_panel` 的右边界改为「整窗右缘 − 右侧面板常量（strip 28 + dock 372）」与
egui 给的剩余区取小——布局常量就在手边，比依赖第三方内部状态稳。

### 7.5 数据与格式零破坏

- `GradeParams` / 工程文件 / MCP 工具 / 导出链路：**一个字段没动**；
- `settings.json` 只加 `panel_solo`（`Option<bool>`，缺省单开），老文件读进来照常；
- 折叠键做了映射（`state::legacy_group_key`）：`color→basic`、`parametric/levels→curve`、
  `hsl/mono→mixer`、`grain→effects`、`lens/profiles→optics`，`copies` 丢弃——
  老用户调好的折叠偏好不丢；
- `ui.module` 命令的模块序号 0–6（新增 6 = 合成），错误文案同步。
