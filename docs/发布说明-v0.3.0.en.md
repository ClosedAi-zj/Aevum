# Lumen Studio v0.3.0 — release notes

[中文](发布说明-v0.3.0.md) · **English**

The first publicly usable version. From a sequence of camera frames to a finished film:
align → composite → crop (with camera motion) → grade → music → speed ramps and motion blur,
all in one window.

## Requirements

- Windows 10/11 x64.
- No installation: unzip and run. `tools\ffmpeg.exe` serves film export and audio probing;
  delete it and the UI still runs — you just cannot export video.

## Quick start

1. Double-click `lumen.exe` and drag a **frame folder** (or a photo folder) into the window;
2. The workspace dropdown at the top switches between six modules: **Sequence / Deflicker /
   Develop / Compose / Render / Audio**. Each step's output flows into the next automatically;
3. **Develop**: adjust light in the right panel (Basic / Color / Effects / Detail / Grain /
   Lens correction / Color grading …). A blue dot to the right of a group title means that group
   has unsaved-in-session changes; clicking a group header collapses it; "Reset" returns the
   whole group to defaults;
4. **Render**: choose a spec and export video (HEVC / H264); progress shows in the status bar;
5. Top "View" menu: rulers, grid, before/after, show/hide the left preset bar and the right
   panel. "Appearance & Layout" (Ctrl+,): light/dark theme, skin, accent colour, corner radius,
   **density (compact / standard / roomy)**, font size, and four layout axes.

## Preferences and data

- Preferences are written to `%APPDATA%\lumen\settings.json` (theme / accent / radius / density /
  font size / layout); delete the file to fall back to defaults.
- A sequence's guard directory is `<sequence>/.lumen/`: cache and project data live there, and
  deleting it only costs a cache rebuild.
- All processing happens locally; there is no network activity.

## Plugins (experimental)

Filter plugins are separate child processes (protocol: one JSON line + raw tiles, 512-pixel
blocks), so a crash cannot take the canvas down with it:

- Drop a plugin at `%APPDATA%\lumen\plugins\<id>\plugin.toml`, or point `LUMEN_PLUGINS` at a
  plugin directory;
- Run it straight from the "Plugins" menu; the status bar shows progress while it runs, and
  "✕ Cancel" is available at any time;
- Three consecutive crashes of the same plugin prompt you to disable it (cancellations do not
  count).

## Main changes in this version (relative to 0.2.2)

- The interface now follows the design throughout: single-row sliders, gradient-mountain
  histogram, left preset bar, document tabs above the canvas, blue filmstrip selection,
  rearranged status bar; the title bar keeps only the brand mark;
- **Control specification table**: 40+ grading parameters registered in one place — sliders,
  group dots and reset all read the same source, and readouts carry units (px and so on);
- **Row density**: compact / standard / roomy, persisted with the other preferences;
- **Plugin background tasks**: progress reporting + cancel + crash counting, so second-long
  Nik-style plugins no longer freeze the interface;
- 600+ tests passing; the headless self-check (`--selftest`) passes.

## Known limitations

- Camera Raw / XMP interop and the built-in decoders arrive in later versions (roadmap on the
  repository board);
- Plugin market v1 only covers free plugins plus vendor links (not settled);
- Light-theme contrast on real footage deserves a hands-on pass.

## Command line

```
lumen.exe                 # normal start
lumen.exe --demo          # built-in demo sequence
lumen.exe --selftest      # headless self-check
lumen.exe --mcp           # agent control surface (stdio JSON-RPC)
```
