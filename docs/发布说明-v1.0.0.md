## 一、本版改动

### 算法：降噪「多尺度」的 eps 与真实噪声对齐（唯一算法改动）

旧式子把 eps 当成「对比度门限」而不是「噪声方差」，在 σ=0.02 时给出噪声方差的 86 倍，
方差小的结构（星星、纹理）被判成噪声抹平。改成 `eps = 0.8·σ̂²/rm` 后，eps 回到方差量纲，
`1/rm` 做尺度补偿。（口径：`docs/adobe-algorithm-atlas.md` §46.2，噪声方差下降 > 50% 且
MTF 保持 > 85%；判定位钉在 1024×768。）

| 画幅 | 多尺度 改前（方差↓ / MTF） | 多尺度 改后 |
|---|---|---|
| 512×256（退化画幅，不参与判读） | 72.0% / 64.2% | 26.7% / 93.6%（降噪不足） |
| **1024×768（判定位）** | 74.5% / 44.6% | **53.8% / 90.0% 达标** |
| 1536×1152 | —（本轮才测） | **62.7% / 87.3% 达标** |
| 2048×1536 | 74.9% / 48.7% | **60.3% / 89.5% 达标** |

**观感变化**：开「多尺度」后比以前**更保留纹理，噪点也略多一点**。以前是「糊掉一半细节换干净」，
现在按噪声方差该磨多少磨多少。代价说清楚：同一档 `nr_luma` 下，开多尺度的总降噪量比纯单尺度
低（1024×768：53.8% vs 69.4%），换来 5.5 点 MTF。单尺度分支本版一个字节没动。

### 交付链路

- `scripts/package.sh` 一条命令出包：门槛 → release → 随包 ffmpeg → 自检 → 真实导出 →
  zip（顶层目录、含 `LICENSE` 与 `CHANGELOG.md`）→ `SHA256SUMS` → 解压回验自检形状数。
- ffmpeg 探测改成可复现的三级（`AEVUM_FFMPEG_SRC` → 包内 `tools/ffmpeg.exe` → `PATH`），
  删掉指向已不存在 venv 的死脚本。
- 验收体系独立成 `acceptance/`（`reference/` 参考实现、`oracle/` 冻结金标、`check.sh` 门槛），
  与产品代码分开。
- 版本号一致性成为门槛第 0 关（`acceptance/check_version.py`）：`Cargo.toml` 为唯一真源，
  `Cargo.lock`、README 四处、CHANGELOG 最新标题必须同号。

### 文档与承诺

- README 中英两节把「beta 期不承诺」换成 1.x 的四类兼容承诺，并各加一小节「从 0.5 beta 升级」。
- `CHANGELOG.md` 头部的 beta 期声明同步改写。
- 新增本文件，把已知限制集中到一处（见下）。

### 已在 beta.2 交付、本版未再改动

`xmp` 工具在附着模式下的路由、报错区分「只在服务模式可用」与「未知工具」、三份工具清单收敛到
`mcp_routes` 单一事实源、`.aevum` 被同名文件占住时的可读报错、`--attach` 版本错配时多余命令不进
`tools/list`、输出锐化过冲限幅（8.35% → 2.09%）。细节见 `CHANGELOG.md` 的 `v0.5.0-beta.2` 节。

## 三、已知限制

以下九条不阻断 1.0，但都是用户能撞上的，写在这里而不是散在各版 CHANGELOG 里。

1. **去马赛克默认走 `cell_average`**，方向自适应算法已实现但**默认不启用**；诊断面板可以切，
   **重启即复位**（不做持久化）。默认值保持保守，1.0 不改。
2. **HDR 导出（PQ / AVIF 10-bit）未实现**，界面上只有预留入口，不要当成可用功能。
3. **AI 降噪是实验性的**：没有数值金标、没有客观验收，不要拿它做交付判断。
4. **性能没有 CI 断言，只有人工读数**：共享 runner 的抖动会把门槛变成噪音，所以 bench 只记
   数字、不设卡。1.0.0 的读数在「二、验收数据」表里（口径与机器配置也写在那儿）：帧时间
   0.57–0.79 ms、p95 不超过 1.26 ms，相对 60 fps 的 16.7 ms 预算约 21 倍余量。两点要说白：
   (a) M1 蒙版几何的**指纹缓存命中路径比裸 JSON 解析慢约 2 倍**（0.81 → 1.54 µs），这是
   `0.5.0-beta.1` 之前就记录过的已知项、不是本版引入 —— 靠每帧只算一次（`mask_prep`）摊薄，
   帧级收益已覆盖；要彻底解决得把指纹下推进差量更新。(b) 这些数字只在这台机器上可比，
   换机器不要跨机对比。
5. **真实素材的端到端测试在素材缺失时会跳过**：CI 上跑不到的用例，发布者必须在本机带素材跑一次。
6. **exe 未做代码签名**，Windows 首次运行会弹 SmartScreen 提示（「更多信息 → 仍要运行」）。
   自证办法：用 `dist/SHA256SUMS` 校验下载到的 zip。
7. **`lapse` 这个名字只剩在用户数据里**：`.lapse/` 工程目录与 `lapse-studio` 配置目录仍会被读、
   会被搬（兼容层，不许删）；仓库里的 Python 参考实现已经搬进 `acceptance/reference/`，
   不再借用这个历史名。
8. **`打包.bat` 已删除**：它指向已不存在的 `.venv`。打包统一用 `scripts/package.sh`。
9. **`docs/` 大部分不入版本库**：只把「发布说明」与「1.0.0 验收清单」纳入（`.gitignore` 用
   `docs/*` + 负向规则），其余过程文档保留在本地。
